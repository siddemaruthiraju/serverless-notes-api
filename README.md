# Serverless Notes API

A cloud-native REST API built with Node.js, AWS Lambda, and DynamoDB.

## Features
- Create, read, and delete notes
- JWT authentication
- DynamoDB integration
- CloudWatch logging
- Jest unit tests

## Tech Stack
- Node.js, AWS Lambda, DynamoDB, API Gateway, Jest
